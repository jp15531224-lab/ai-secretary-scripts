# iPhoneショートカット設定手順（食事管理）

所要時間：約15分（初回だけ）。作るのは3本です。

| 名前 | 使い方 | Siri |
|---|---|---|
| **食事** | 話すだけで記録・補正・質問（「カツ丼食べた」「今日何カロリー？」「候補1は記録」「体重77.6」） | 「Hey Siri、食事」 |
| **食事写真** | 写真アプリ等の「共有」→「食事写真」。補足があれば一言 | — |
| **今日の食事** | ワンタップで今日の合計・残り・塩分・確認候補を表示 | 「Hey Siri、今日の食事」 |

> 送り先URLと合言葉は、Google Drive「iCloud外部脳／食事・健康管理／食事管理_ショートカット設定値（秘密）」にあります。
> iPhone の Google Drive アプリで開いてコピーしてください。**このURLと合言葉は他人に教えないでください。**

---

## 1. 「食事」（音声）

ショートカットアプリ →「＋」→ 名前を「食事」にして、次のアクションを順に追加します。

1. **テキストを音声入力**（Dictate Text）
   - 言語：日本語　／ 聞き取りを停止：「一時停止後」
2. **URLの内容を取得**（Get Contents of URL）
   - URL：設定値ファイルの「送り先URL」
   - 方法：**POST**
   - ヘッダ：なし
   - 本文を要求：**JSON**、次の3項目を追加
     | キー | 種類 | 値 |
     |---|---|---|
     | token | テキスト | 設定値ファイルの「合言葉」 |
     | text | テキスト | （変数）音声入力されたテキスト |
     | source | テキスト | ショートカット |
3. **結果を表示**（Show Result）：（変数）URLの内容

## 2. 「食事写真」（写真＋ひと言）

1. ショートカットの詳細（ⓘ）で「**共有シートに表示**」をオン、受け付ける種類は「**イメージ**」だけ
   - 「入力がない場合」：「写真を撮る」または「写真を選択」
2. **画像のサイズを変更**：幅 **1024**（高さは自動）
3. **イメージを変換**：形式 **JPEG**、画質 0.7、メタデータを保持 オフ
4. **Base64エンコード**：改行 **なし**
5. **画像の詳細を取得**（ショートカット入力 → **撮影日**）
6. **入力を要求**：テキスト、プロンプト「補足があれば（例：半分食べた、友達の分）。なければそのまま完了」
7. **テキスト**：`（撮影日時 [撮影日]）[入力を要求の結果]`
8. **URLの内容を取得**：URL・方法は1と同じ。本文 JSON：
   | キー | 種類 | 値 |
   |---|---|---|
   | token | テキスト | 合言葉 |
   | text | テキスト | （変数）7のテキスト |
   | image | テキスト | （変数）Base64エンコードの結果 |
   | source | テキスト | 写真 |
9. **結果を表示**

> 料理名の入力は不要です。写真だけなら「写っている料理を全部食べた」として仮記録し、あとで「食事」で「これ半分食べた」「これは友達の料理」と言えば補正されます（新しい食事として二重には入りません）。
> 同じ写真を2回送っても二重登録されません。

## 3. 「今日の食事」（ワンタップ）

1. **URLの内容を取得**：URL・方法は1と同じ。本文 JSON：token＝合言葉、text＝`今日の状況は？`、source＝ショートカット
2. **結果を表示**

ホーム画面に追加（共有ボタン →「ホーム画面に追加」）すると1タップで見られます。

## 話し方の例

| 話す内容 | 動き |
|---|---|
| 「今カツ丼食べた」 | 送信時刻で記録 |
| 「パスタ大盛り食べた」「卵かけご飯は小盛り」 | 量を調整して記録 |
| 「焼き鳥もも3本、胸肉2本」 | 2品に分けて記録 |
| 「ビール2杯飲んだ」 | アルコール量も記録 |
| 「昨日の夜中2時にラーメン食べた」 | 午前6時区切りで前日分に記録 |
| 「これ半分食べた」「刺身は半分、天ぷらは全部」「ご飯は残した」「スープは飲んでない」 | 直前の記録を補正 |
| 「これは友達の料理」「さっきのカツ丼は取消」 | 集計から外す（記録は消さずに履歴が残る） |
| 「これは昨日食べたもの」 | 日付を補正 |
| 「今日何カロリー？」「あと何カロリー食べられる？」「今日の塩分は？」 | 今日の集計を返答 |
| 「昨日は食べすぎた？」「今週の平均は？」 | 日別・7日平均から返答（単日でなく週平均で判断） |
| 「候補1は記録」「候補2は不要」 | PLAUD・ボイスメモから見つかった候補を処理 |
| 「体重77.6」 | 体重を記録（週1回程度でOK） |

## うまく動かない時

- **何も返ってこない／「Accepted」とだけ出る**：合言葉が違う可能性。設定値ファイルからコピーし直す。
- **時間がかかる**：写真は10〜20秒ほどかかります。
- **数字がおかしい**：「さっきの○○は取消」で外し、言い直してください。補正の履歴は食事DBの「補正履歴」シートに残ります。

※栄養は推定値です。医療上の判断には使えません。
