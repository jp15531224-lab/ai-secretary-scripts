# ChatGPT「食事記録」GPT の設定手順

所要時間：約5〜10分（初回だけ）。**パソコンのブラウザ、または iPhone の Safari で chatgpt.com を開いて行います**（GPT の作成は ChatGPT アプリではできない場合があります）。ChatGPT の有料プランが必要です。

貼り付ける値（スキーマ・合言葉）は Google Drive「iCloud外部脳／食事・健康管理／ChatGPT設定値（秘密）」にあります。

## 手順

1. chatgpt.com を開く → 左のメニュー「**GPT**」→ 右上の「**＋ 作成**」
2. 上のタブで「**構成**」を選ぶ
3. 次のように入力
   - **名前**：食事記録
   - **説明**：食べたものを送るだけで記録・集計
   - **指示**：秘密ファイルの「■指示」の部分をすべて貼り付け（このリポジトリの `docs/meal/gpt_instructions.txt` と同じ内容）
   - **会話のきっかけ**：「今日何カロリー？」「今週の平均は？」「確認候補を見せて」
4. **機能**のチェックはすべて外す（ウェブ検索・キャンバス・画像生成・コードインタープリター）
5. 一番下の「**新しいアクションを作成する**」
   - **認証**：歯車 →「**APIキー**」
     - APIキー：秘密ファイルの「■合言葉」
     - 認証タイプ：「**カスタム**」、カスタムヘッダー名：`x-meal-token`
     - 「保存」
   - **スキーマ**：秘密ファイルの「■スキーマ」をすべて貼り付け（`sendMealMessage` が1つ表示されればOK）
   - プライバシーポリシーは空欄でよい（自分だけで使うため）
6. 右上の「**作成**」→ 共有範囲は「**自分だけ**」→「保存」

## 使い方（iPhone の ChatGPT アプリ）

- 左メニューの「食事記録」を開き、普段どおり打つか、マイクで話すか、写真を貼る。
  - 「今カツ丼食べた」「焼き鳥もも3本、胸肉2本」「ビール2杯」
  - 写真だけ貼る →「これ半分食べた」「これは友達の分」と続けて補足
  - 「今日何カロリー？」「昨日は食べすぎた？」「今週の平均は？」
  - 「候補1は記録」「候補2は不要」「体重77.6」
- 初回は「hook.eu1.make.com と通信しますか？」と聞かれるので「**常に許可**」。
- よく使うなら、チャットを長押しして「ピン留め」しておくと開くのが早くなります。

## 写真の扱い

ChatGPT が写真を見て「料理名・量・調理法」を文章にして送ります（写真そのものは送りません）。量の見立てがずれていたら、その場で「ご飯は小盛り」などと補足してください。

## うまく動かない時

- 「記録できませんでした」が続く：合言葉の貼り間違い（前後の空白に注意）か、ヘッダー名の違い（`x-meal-token`）。
- 毎回確認が出る：通信の確認で「常に許可」を選ぶ。
- 返答が来るまで約10〜20秒かかります。

※栄養は推定値です。医療上の判断には使えません。
