# 全厚済セミナー 参加・フォロー台帳 — ChatGPT連携の設定と点検

## 構成（既存のまま）

| 部品 | 場所 |
|---|---|
| 台帳（DB） | スプレッドシート「全厚済セミナー一覧」（シート：一覧／人物／参加記録／確認待ち候補） |
| API | 同スプレッドシートの Apps Script をウェブアプリ公開（URL は「ChatGPT設定」B1） |
| プログラム | リポジトリ直下の `zenkosai_seminar_list.gs`（Apps Scriptでは「コード.gs」）と `参加者管理.gs` |
| ChatGPT 側 | カスタムGPTのアクション `seminarApi`（指示＝「ChatGPT設定」B4、スキーマ＝B5。どちらも chatgptSettings で作る） |

MCPサーバーやMakeのシナリオは使っていません（Makeにあるのは食事記録用だけ）。

## 2026-10-22 の点検結果

- API（ウェブアプリ）は稼働中。register / update / roster / history / people / candidate_add / candidates / candidate_confirm がすべて正常に応答。
- 重複防止：同じ人×同じ回の再登録は `duplicate=true` で弾かれ、行は増えない。確認待ち候補も同じ資料・同じ人なら増えない。
- 講師が同じで回が複数ある時は `needs_confirmation` で選択肢を返し、勝手に登録しない。
- **一覧に2026年10月の回が0件**（スクショ取り込みは11月以降のみ）。10/22 加古川・又吉・BE は一覧に無いため、正しく呼べても `seminar_not_found` になる。
- 「このチャットから登録機能を呼び出せない」はAPIのエラーではなく、ChatGPT側の会話に `seminarApi`（action付き v1.1.0 スキーマ）が付いていない時の文言。

## ChatGPT側の設定（JPの作業、約5分・パソコンで）

スプレッドシートの「ChatGPT設定」B4・B5は、プログラムより古い版のまま（B5にボイスメモ読み取り memos が無い）。
指示文の改善は `参加者管理.gs` に組み込んだので、次の手順で B4・B5 を作り直してから GPT に貼る。

1. スプレッドシート →「拡張機能」→「Apps Script」→ 左の「参加者管理.gs」を開く。
2. 中身を全部消して、GitHub の最新 `参加者管理.gs` を貼って保存（https://raw.githubusercontent.com/jp15531224-lab/ai-secretary-scripts/add-zenkosai-seminar-list/参加者管理.gs を開いて全選択→コピー）。「コード.gs」は触らない。
3. 左の「コード.gs」を開き（関数の選択欄は開いているファイルの関数しか出ないため）、上の関数選択で **chatgptSettings** を選んで「実行」。B4（指示）と B5（スキーマ）が新しくなる。
   - デプロイのやり直しは不要（変わったのは指示文を作る部分だけで、台帳の動きは変わらない）。
4. ChatGPT → セミナー用GPT →「編集」→ 指示を全部消して **B4** を貼る。
5. アクション → スキーマを全部消して **B5** を貼る（認証：なし）。下の一覧が `seminarApi` 1つならOK。
6. 「更新」で保存し、そのGPTの文字入力で「動作テスト太郎の履歴を見せて」→ 11/23 又吉BT が返れば接続成功。

※ スキーマには合言葉が入るため、このリポジトリ（公開）の `schema.json` は伏せ字の参考用。貼るのは必ずB5から。
※ `instructions_v1.2.txt` は B4 に出来上がる指示文と同じ内容（確認用）。

## 音声モードについて

- アクション（seminarApi）が呼べるのは、そのGPTの会話の中だけ。通常のChatGPTの会話からは呼べない。
- GPTの中で音声モードからアクションが呼べるかは、ChatGPTの仕様変更が多く、ここからは検証できない（不明）。
- 確実な方法：GPTの会話で、入力欄の**マイク（音声入力）ボタン**で話す。文字として送られるので、テキストと同じ経路で必ず登録できる。

## テスト用データ（削除してよい）

「参加記録」シートの「動作テスト太郎」「動作テスト次郎」の2行、「人物」シートの同2行、「確認待ち候補」の1行（状態＝却下）。いずれもメモ「動作テスト用データ（削除可）」、11/23 又吉BT の回。
